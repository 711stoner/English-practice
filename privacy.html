隐私说明

本产品尚处开发测试阶段。本说明在正式运营前须补齐经营者身份、联系邮箱、存储地点、数据保存期限与适用法律条款。

保存在浏览器本地的数据

你手动粘贴的、来自不同社交平台的原创文字、语言风格档案、产品信息、候选帖子和评论草稿，默认存储在 Chrome 扩展的本地存储中。卸载扩展或清除数据可能造成丢失。

使用云端 AI 的数据

当你主动选择第三方 Gemini 或 OpenRouter 并勾选知情确认时，插件会把当前任务需要的文字直接发送给对应模型服务商；不会经过本产品服务器。Google 提示 Gemini 免费层内容可能用于改进其服务，且可能有人工审核，不应提交敏感资料。选择 Cloudflare 托管 AI 并明确授权时，才会把必要文字发送给自有 Worker。WebLLM/Qwen 本地 AI 首次需从 Hugging Face 等来源下载模型权重文件，下载请求不携带你的原创语料。模型加载后，文字分析和生成在设备本地进行；缓存被清除时可能需要重新下载。

账号及计费信息

云端账户服务器保存经验证的邮箱、会话标识摘要、使用次数与订阅状态。支付卡资料由支付服务商处理，插件不保存银行卡卡号。

你的控制

插件提供删除全部本地数据入口。云端账户删除与数据导出功能在正式上线前还需要补齐，不应在该功能上线前公开运营。

X 官方搜索推荐

仅当 X 官方搜索服务已开通、且用户主动点击推荐或主动允许保存产品后自动搜索时，插件才向私有服务发送产品简介和搜索关键词。不会发送个人原创语料或风格档案。只有用户选中的帖子会被保存为本地候选帖；不会代用户发布评论。

开发者本地第三方数据源测试

未公开发布的个人测试版可选择 Sorsa 搜索公开 X 帖子，仅主动发送搜索词，不会上传个人原创语料或风格档案。Key 只临时保存于浏览器会话；Sorsa 并非 X 官方授权的搜索接口，是否符合 X 的数据条款仍须独立核实。

最近一次搜索结果的本地缓存

为方便用户写完一条评论后继续选帖，插件仅在本机保存最近一次搜索及主动加载的分页结果（最多200条公开帖文、作者、链接和数据来源）。返回及重新打开插件不会再次搜索。新结果会覆盖旧缓存，删除全部本地数据也会清除缓存；第三方 API Key 不会包含在其中。
